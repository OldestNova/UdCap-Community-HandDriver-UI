# 宇叠社区驱动 (UI)
基于[UdCap 宇叠动作捕捉手套社区驱动核心](https://github.com/OldestNova/UdCap-Community-HandDriver-Core)的用户 GUI。

## 当前功能支持状态
 - [x] UdCap 宇叠动作捕捉手套社区驱动核心 中的所有功能
 - [x] VMC 协议支持
 - [ ] OSC 协议支持
 - [ ] 广播协议支持(将会实现为组播以避免广播风暴并提供对应客户端以兼容)
 - [ ] SteamVR 协议支持
 - [x] 简易模式(消费者版)界面
 - [ ] 高级模式(企业版)界面
 - [x] 控制器支持
 - [ ] 3D 预览
 - [ ] 关节微调
 - [ ] 控制器标定和配置

该库跟随核心库功能更新，为社区驱动核心的第一方用户界面实现。
